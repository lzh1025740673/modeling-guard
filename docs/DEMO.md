# A 60-second walkthrough

This is a software acceptance demonstration using five synthetic reference/prediction pairs. It does not train a model or solve a contest problem.

1. Download ZIP, extract, and open a terminal in the folder.
2. `python -m modeling_guard init demo-project`
3. Open `demo-project/experiment.json`. Point out the 10-second limit, 2-run allowance, file list, and MAE threshold of 2.0.
4. Review the small Python script and clearly synthetic CSV.
5. `python -m modeling_guard approve demo-project --teacher "Demo reviewer"`
6. `python -m modeling_guard run demo-project`
7. Open the printed report path: MAE 1.0, PASS, input/output hashes, and the teacher-review caveat.
8. Edit one prediction in the original CSV and run again: STOP, because the old approval no longer matches.

The [example HTML report](demo-report.html) was generated by a real local Windows demo run. Download/open it to preview the layout. Timing is specific to that one machine/run. No student information or real contest data is included.

For recording a demo video, show the actual terminal and report, retain the synthetic-data label, and do not imply unmeasured token savings or scientific correctness.
