# 团队执行约定

教师 / ChatGPT Pro 负责赛题分析、模型方案和重大数学决策。学生 Codex 只读取已批准的 TASK_BRIEF.md，实现代码、运行批准实验并记录真实结果。没有批准方案或完整输入时，生成 reports/HUMAN_REVIEW.md 并停止，不自行补数据、设计模型或猜测含义。

## 当前阶段与成本

- 开始先读本文件及 TASK_BRIEF.md；只执行其中当前阶段。输入附件和上游 Skill 只读。
- 仅按需读取 math-modeling 当前角色和必要参考，不遍历整库；不加载论文角色，不自动写论文，不自动转入下一阶段。
- 本项目明确关闭上游默认 M1/P1/P2/W1/W2 自动 Subagent 派发，以及自动回退改写模型的流程。教师负责复核；不得声称上游独立 Subagent 门禁已通过。只有教师另行明确批准具体子任务才可启用。
- 图表只按 TASK_BRIEF 批准的清单生成；本项目不采用上游每类三张、合计九张或论文八张的默认配额。
- 不自行更换模型、求解器路线、目标、约束、抽样口径、标签或评价指标。超时降级、正则化等若改变方案，须人工决定。
- 默认不联网、不自动安装依赖、不下载大型数据、不训练神经网络、不启动或购买云 GPU、不作大规模搜索，不修改全局 Codex 配置、登录、代理或凭据；确需时先停止报审。
- 仅记录真实命令、退出码、日志、运行时间、依赖版本、随机种子、输入 SHA256、参数和复现命令；不得虚构精度、图表或论文结论。
- TASK_BRIEF 必须给出批准的运行范围与预算；预算不明时先报审。禁止无界重试或自动扩展任务。

## 必须停止的条件

1. 赛题或数据含义存在会改变模型的歧义。
2. 需要改变教师提供的核心模型路线。
3. 怀疑存在数据泄漏。
4. 单位、标签或样本含义无法确认。
5. baseline 无法正常运行。
6. 模型出现 NaN / Inf，经过最多两次有依据修复仍失败；每次修复记录证据，若涉及路线变更则立即停止。
7. 需要增加付费 GPU 资源。
8. 需要大规模超参数搜索。
9. 新模型明显不优于 baseline；比较按已批准指标、划分和容差，不自行反复搜索以追平。
10. 结果不足以支持论文结论。

## 停止与交付

触发以上任一条件或缺少批准方案/输入时，按 templates/HUMAN_REVIEW_TEMPLATE.md 生成 reports/HUMAN_REVIEW.md，随后立即停止工具调用和阶段推进，只报告文件位置并等待人工决定。写报告不是继续执行的授权。若已有未解决报告，先保持停止；只有新的教师决定明确解决阻塞、更新批准范围后才能继续，不自动删除报告。

正常完成当前阶段后，按 templates/STAGE_REPORT_TEMPLATE.md 生成 reports/STAGE_REPORT.md，然后停止。阶段报告不等于教师验收通过。未实测项必须标注未验证。
